# Overrides

Drop a `<ISO3>.json` file here to override the traced zones for one country.
Supported today:

```json
{ "level": 2, "reason": "Map not yet updated after advice change of 2026-11-01" }
```

`level` colours the whole country (1 groen, 2 geel, 3 oranje, 4 rood).
Use it when the official map is missing or clearly stale; remove it once the map is fixed.
